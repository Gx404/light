The template adaptations remove the demo controls, promotional links, analytics, screenshot tools, upstream automatic splashes and input handlers. The engine exposes a small pointer and pause API, uses procedural dithering without an external image, caps pixel density, stops after idle periods, and pauses when the page is hidden. Page-level code adds pointer input, a short randomized opening sequence, reduced-motion handling and graceful failure when WebGL is unavailable.

The page layout is independently implemented. No third-party branding, registration numbers or proprietary site assets are included.
